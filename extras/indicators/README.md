# Indicators

Notes on what indicators mean — what an indicator's levels and signals stand
for — so a check reading a story can tell whether a reference to one is really
ambiguous or already settled by what the indicator is.

This is meaning, not mechanics. How an indicator is read on a particular
charting platform — the names of its plots, how its values are fetched — belongs
to that platform, not here.

## Reading an indicator named by a story

Where a story names an indicator, look for a subfolder here whose name matches
it, ignoring case, spaces and hyphens. A folder whose name is only the start of
the one the story names is a different indicator, so leave it alone. Read the
notes in the matching folder; an indicator without one has nothing to read.

Inside the folder, look for a file called indicator.md and start there.
